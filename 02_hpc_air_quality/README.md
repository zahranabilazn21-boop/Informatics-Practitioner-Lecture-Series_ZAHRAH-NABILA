# Kasus 2 — HPC untuk Pemrosesan Data Sensor Lingkungan
Menggunakan dataset pengukuran kualitas udara UCI (ID 360). Kode mengukur waktu agregasi statistik per kolom secara serial dan paralel. Ini memakai data pengukuran nyata historis, tetapi hanya demonstrasi prinsip pemrosesan paralel pada satu komputer; bukan benchmark supercomputer.
