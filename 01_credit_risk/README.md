# Kasus 1 — Analisis Risiko Kredit
Dataset UCI Default of Credit Card Clients memuat karakteristik pelanggan dan label pembayaran default. Kode membersihkan nilai hilang, meninjau ketidakseimbangan kelas, melatih Logistic Regression, dan melaporkan precision, recall, F1, ROC-AUC. Dataset berasal dari Taiwan dan tidak boleh disebut sebagai data piutang perusahaan Indonesia.
