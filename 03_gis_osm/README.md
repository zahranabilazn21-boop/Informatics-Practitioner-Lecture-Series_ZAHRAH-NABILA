# Kasus 6 — GIS menggunakan OpenStreetMap
Mengambil data fasilitas publik dari OpenStreetMap menggunakan OSMnx berdasarkan nama wilayah. Kode menghitung koordinat pusat fasilitas dan menyimpan tabel CSV. Data OSM berasal dari pemetaan kolaboratif dan perlu diperiksa kelengkapan serta akurasinya sebelum digunakan dalam keputusan resmi.
