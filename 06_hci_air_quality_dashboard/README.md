# Kasus 4 — Dashboard HCI & Visualisasi Data
Dashboard Streamlit memvisualisasikan data kualitas udara historis UCI. Pengguna dapat memilih sensor/variabel numerik, melihat ringkasan, grafik, dan tabel. Dataset memiliki kode nilai hilang khusus pada beberapa kolom, sehingga kode mengonversinya menjadi missing values.
