# Kasus 5 — Machine Learning untuk Permintaan/Penjualan
Menggunakan UCI Online Retail (ID 352), dataset transaksi ritel historis dari Inggris pada 2010–2011. Kode mengagregasi jumlah unit terjual per hari dan melatih model regresi sederhana berbasis fitur kalender. Pembatalan, kuantitas negatif, dan transaksi tidak valid ditangani secara eksplisit.
