# Kasus 3 — Analisis Lingkungan dan Kebakaran Hutan
Dataset UCI Forest Fires (ID 162) berisi pengamatan cuaca/lingkungan dan area kebakaran hutan di Portugal. Kasus ini menganalisis pola serta membangun model regresi area terbakar. Ini tidak sama dengan mengatribusikan penyebab deforestasi dari citra satelit.
